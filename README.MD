# Quote Scraper

This is a simple Python script for scraping quotes, authors, and tags from websites like [http://quotes.toscrape.com](http://quotes.toscrape.com). It extracts structured content from HTML pages and prints the results to the command line.

## Features
- Extracts quote text, author names, and tags
- Designed for educational and testing use on static HTML pages
- Uses `requests` for HTTP handling and `BeautifulSoup` for parsing

## Requirements
- Python 3.x
- Install dependencies using: pip install requests beautifulsoup4

## Output
The script prints each quote on the page along with:
- The quote text
- The author's name
- A list of tags associated with the quote
